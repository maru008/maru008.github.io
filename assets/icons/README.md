# アイコンの出典

2026年9月14日に、各リンク先を識別する目的で以下の公開アイコンを取得しました。サイトでは改変せず、リンク先の名称と併記しています。

- `researchmap.ico`: researchmap公式サイトのfavicon（<https://researchmap.jp/favicon.ico>）
- `j-global.ico`: J-GLOBAL公式サイトのfavicon（<https://jglobal.jst.go.jp/build/resources/images/favicon/favicon.ico>）
- `orcid.svg`: ORCID公式iDアイコン由来（<https://commons.wikimedia.org/wiki/File:ORCID_iD.svg>、原典はORCID、CC0）
- `mil.png`: メディア情報学研究室公式サイトのサイトアイコン（<https://www.milcis.doshisha.ac.jp/wp-content/uploads/2022/12/lab_logo.png>）
- `link.svg`: 未知のリンク種別に使用する、このリポジトリ独自の汎用リンクアイコン

ORCID iDアイコンは、ORCIDの表示ガイドラインに従い、色や形を変更せず使用します。
